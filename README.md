# MV（Maaya Village）コンセプトLP

「エネルギー問題研究所」のコンセプトを伝えるランディングページです。

## ファイル構成
- `index.html` — LP本体（これを開くと表示されます）
- `images/hero-bg.png` — ヒーロー（最上部）の背景画像

## GitHub Pagesでの公開手順
1. GitHubでリポジトリを作成
2. `index.html` と `images` フォルダ（中の画像ごと）をアップロード
   ※ index.html と images フォルダは必ず同じ階層に置いてください
3. Settings → Pages で公開ブランチを指定
4. `https://ユーザー名.github.io/リポジトリ名/` で公開されます

## 確認方法
`index.html` をブラウザで開くと表示されます。
※ index.html だけを単体で移動すると背景画像が表示されません。
　必ず images フォルダごと一緒に扱ってください。
